# Packs

Ready-made voice commands. In Hearsay, open Settings → Sites → **Import a pack** and choose a file.

| Pack | Commands |
| --- | --- |
| [youtube.json](youtube.json) | Play or pause, skip, rewind, captions, fullscreen, mute, next video, search |
| [wikipedia.json](wikipedia.json) | Look things up, random article |
| [google.json](google.json) | Search, open a result by number (JavaScript) |

To add one, build it in settings, export it, and open a pull request. The format is in the main [README](../README.md#sharing-packs).
